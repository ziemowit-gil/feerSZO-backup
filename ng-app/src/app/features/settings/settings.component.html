URL API (karty30.php) link Pełny URL lub ścieżka względna, np. https://feer.org.pl/api/v1/karty30.php Tytuł aplikacji Nazwa organizacji Base href (katalog na serwerze) Musi odpowiadać katalogowi, w którym wgrano pliki.
info Jak skonfigurować na serwerze?
  1. Wgraj pliki z ng-app/dist/ng-app/browser/ do katalogu /newUI/ na seohost.pl
  2. Edytuj plik /newUI/app.config.json bezpośrednio na serwerze — zmień apiUrl na pełny URL backendu PHP
  3. Alternatywnie użyj formularza powyżej, pobierz config i wgraj go jako /newUI/app.config.json
