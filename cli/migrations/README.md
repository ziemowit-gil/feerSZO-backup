# Archiwum migracji

Ten katalog zawiera pliki migracji bazy danych dla systemu Rejestr Umów.

Pliki migracji (`migrate_*.php`) zostały przeniesione tutaj po wykonaniu. Nie należy ich uruchamiać ponownie.

## Zarządzanie migracjami

Panel zarządzania migracjami dostępny jest pod adresem `/admin/migrations.php` (tylko dla administratorów).
